# Supermarket Sales Analysis

This project analyzes supermarket sales data to evaluate business performance, revenue trends, and product contribution using SQL and Power BI.

## Overview
- Revenue: ~$307K  
- Orders: 5,510  
- Time: Jan–Mar 2019  

## Key Insights
- Revenue peaks on specific days, showing demand spikes  
- January has the highest monthly revenue  
- Payment methods are evenly distributed  
- Product performance varies across branches  

## Business Impact
The analysis helps optimize product strategy, branch performance, and revenue growth decisions.
